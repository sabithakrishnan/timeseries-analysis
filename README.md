# timeseries-analysis
This is the repository i have created for showcasing timeseries analysis  using various Machine learning and deep neural network. The data set I have used is UCI air quality dataset. Slowly I'm building each model and when a certain number of model is created I will compare their performances.
I have categorised the algorithms in to 3 types: statistical modelling, Machine learning models and neural network models
Under statistical modelling I have used ARIMA,SARIMA,ETS and prophet. Developed the forecasting graph, analysed their metrics
under machine learning i have used Light gbm, XG boost and randomforest.Developed the forecasting graph, analysed their metrics
under neural network i have used CNN,LSTM and transformer. Developed the forecasting graph, analysed their metrics
By comparing all these I concluded LSTM performs best followed by random forest.
statistical models like ARIMA and SARIMA specially built for forecasting performed very poor
